# Edit 工具陷阱

## 4. Edit 工具必须同时提供三个参数
**现象**：Edit 工具报错。

**根因**：未正确使用 Edit 工具，参数缺失。

**正确做法**：
1. **Edit 必须同时提供 `file path`、`old string`、`new string` 三个参数，缺一不可。** `old string` 必须与文件内容逐字符完全匹配（含缩进），匹配失败会直接报错，不会自动修正。主子代理调用前需先 Read 文件确认内容，再发起 Edit。
2. **Edit 匹配失败处理**：** 如果 `old string` 匹配失败，重新 Read 文件获取最新内容，不要盲目重试。
